# Development-of-multi-game-suite-using-SFML
The Development of Multi-Game Suite Using SFML is a C++ based project that combines multiple classic games into one interactive platform using SFML. It helps users learn game development concepts like graphics, input handling, and modular design while providing an engaging and educational gaming experience.

## 📌 Project Overview

The **Development of Multi-Game Suite Using SFML** is a C++ based project that integrates multiple classic games into a single interactive platform using the **SFML (Simple and Fast Multimedia Library)** framework. This project is designed to provide both entertainment and practical learning by demonstrating concepts such as graphics rendering, object-oriented programming, modular design, real-time user interaction, and multimedia application development.

The system allows users to access and play different games from one unified interface, making it a scalable and user-friendly solution for beginners, students, and gaming enthusiasts.

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone <repository-link>
```

### 2️⃣ Install SFML

* Download SFML from the official website
* Configure include and library paths in your compiler
* Copy required SFML DLL files into the project folder

### 3️⃣ Compile the Project

```bash
g++ main.cpp -o game -lsfml-graphics -lsfml-window -lsfml-system
```

### 4️⃣ Run the Application

```bash
./game
```
